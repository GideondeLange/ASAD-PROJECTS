ASAD permanent QR code
======================
Scans to: https://asad.co.za/qr   (which redirects to the home page)

DO NOT change the printed address. To change where scans go, edit ONLY the
"0.3 PERMANENT QR CODE ADDRESS" rule in public/.htaccess. Stickers never need reprinting.

Files
  asad-qr-code.svg   vector - give this to the sticker/sign printer (stays sharp at any size)
  asad-qr-code.png   3000 x 3000 px - for Word, Canva, email, quick use

Settings: static code (no account, no subscription, nothing to expire), black on white,
highest error correction (H, survives about 30% damage), 4-module blank border.
Keep the blank border white and at least 2 cm wide on a sticker; never invert the colours.
Minimum printed size: about 2 cm. Test-scan a printed proof with 2-3 phones before a big order.
